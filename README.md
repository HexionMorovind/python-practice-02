# python-practice-02
# Практическая работа 1. Расчёт стоимости покупки

## Назначение проекта

Данный проект представляет собой консольное приложение на языке Python,
разработанное в рамках практической работы №1 (Вариант 4).

Программа предназначена для расчёта итоговой стоимости покупки товара
с автоматическим применением скидки в зависимости от общей суммы заказа.

## Какие задачи решает программа

Программа выполняет следующие функции:

- Запрашивает у пользователя данные о товаре через консоль:
  - название товара;
  - цену за единицу;
  - количество единиц.
- Вычисляет исходную стоимость покупки по формуле:
  `стоимость = цена × количество`.
- Определяет размер скидки в зависимости от суммы покупки:
  - менее 5000 руб. — скидка отсутствует (0%);
  - от 5000 до 9999 руб. — скидка 5%;
  - от 10000 до 14999 руб. — скидка 10%;
  - от 15000 руб. и выше — скидка 15%.
- Рассчитывает размер скидки в денежных единицах.
- Вычисляет итоговую стоимость покупки с учётом скидки.
- Выводит подробный отчёт по покупке.
- Обрабатывает некорректный ввод пользователя (буквы вместо чисел).

## Требования

- Python 3.6 или выше
- Дополнительные библиотеки не требуются

## Запуск

```bash
python variant4_purchase.py
```

## Как пользоваться программой

1. После запуска программа последовательно запросит три значения:
   - Название товара — любая строка (например, `Клавиатура`);
   - Цена — число, можно дробное (например, `4500` или `199.99`);
   - Количество — целое число (например, `3`).
2. Введите значения и нажмите Enter после каждого.
3. Если введены некорректные данные (например, буквы вместо числа), программа выведет сообщение об ошибке и завершит работу.
4. После корректного ввода программа выведет отчёт с исходной стоимостью, размером скидки в процентах, размером скидки в рублях и итоговой стоимостью.
